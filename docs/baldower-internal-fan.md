# Internal Fan support for Baldower

`nx_sim_internal_fan_schema(document)` inspects an uncommitted native Internal Fan builder in an active NX MULTIPHYSICS Flow or Coupled Thermal-Flow SIM. It reports property defaults and types, selector descriptor strings, and target-set count. Use it in an isolated coupon before implementing face selection, orientation, volume-flow/curve binding and motor heat.

The diagnostic requires the solver-idle guard. It destroys the temporary builder and rolls back to an undo mark, then checks objects, expressions, fields, selected-solution boundaries and the modified flag against the original snapshot. Cleanup or restoration failure reports a partial outcome rather than claiming success. It does not save or solve.

Current validation: 54 selected cleanup, precondition, failure, flow-boundary and tool-surface tests pass. Native NX 2606 inspection and state restoration also pass, as detailed below. Fan creation, solver-export semantics and numerical acceptance remain unverified.

Next: implement explicit native selection and SI readback in the isolated two-region coupon; verify a single internal connection in exported solver input; then validate mass/energy conservation, orientation reversal and mesh sensitivity. External inlet/outlet pairs are not substitutes for an internal interface.


## Native NX 2606 verification

The committed implementation was exercised in a fresh graphical NX 2606 session against an isolated, saved two-block Coupled Thermal-Flow SIM. Inspection succeeded with one target set and 22 properties. Inventory and modified-state rollback checks passed; an independent `nx_sim_documents` readback matched before and after, with all three documents unmodified. No boundary was committed and no solver was launched. See [native evidence](evidence/internal-fan-schema-nx2606.json).

Pass `document` as the live part reference returned by `nx_sim_documents`; a filesystem path is not an object reference. An initial path-based call was rejected before builder inspection.

`Heat Generated by Fan` is a native double in watts. `Orientation Vector` is a native vector property. Volume Flow and Fan Curve use scalar-field wrappers. Default flow expressions are dimensionless sentinel values and cannot be treated as valid prescribed flow. `GetPropertyDescriptorName` returned empty strings for all properties in this fixture; selector choices therefore still need separate inspection. This result validates inspection and cleanup only. Boundary creation, face selection, direction, exported solver semantics and numerical acceptance remain unverified.
